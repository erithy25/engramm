# Archived Claude Code edit logs

These `*.edits.json` files are protocols of Claude Code `Edit` tool calls
from the original development sessions on `/Users/erikthye/engramm/` —
`old_string`/`new_string` pairs, not source code. They were the only surviving
artifact after the original working tree was lost, and commit `a1af719` was
reconstructed from them.

They are kept because they are currently the most complete record of the
project's measurement history: the `D*.md.edits.json` files contain full
result tables and protocol text that the recovered `docs/D*.md` fragments lack.

They are **not** project content and should never return to the source tree.
When the D-documents are restored from these logs, this directory can be
deleted.
